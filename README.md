# Обед — заказ обедов на завтра

Статический сайт (HTML + JS) на Supabase. Сборка не нужна. Время приёма заказов (18:00–22:00) считается по Астане.

## Файлы
- `schema.sql` — база данных, права доступа, бонусы, хранилище фото
- `make_admin.sql` — команда, чтобы назначить первого админа
- `index.html`, `app.js`, `style.css` — сайт
- `config.js` — адрес проекта и публичный ключ

## Запуск
1. **База.** Supabase → SQL Editor → New query → вставьте весь `schema.sql` → Run. Должно быть "Success".
2. **Вход без почты.** Authentication → Sign In / Providers → Email → выключите **Confirm email** → Save.
3. **Ключ.** Project Settings → API Keys → скопируйте **Publishable key** (`sb_publishable_...`, или `anon`).
   Вставьте в `config.js` вместо `ВСТАВЬТЕ_PUBLISHABLE_KEY`. Секретный ключ (`secret`/`service_role`) НЕ вставляйте.
4. **GitHub.** Создайте репозиторий и загрузите все файлы (кроме этого README, если не нужен).
5. **Vercel.** Add New → Project → выберите репозиторий → Framework Preset: **Other** → ничего не меняйте → Deploy.
6. **Первый админ.** Откройте сайт, зарегистрируйтесь (сначала нужна хотя бы одна компания, см. ниже — добавьте её
   прямо в Supabase: Table Editor → companies и departments). Потом запустите `make_admin.sql` с вашим номером.
   Дальше всё делается в админке: Компании, Меню, Настройки (номер для оплаты и WhatsApp), Клиенты.

## Важно
- Забытый пароль: админ нажимает «Сбросить пароль» в «Клиентах» и сообщает новый пароль человеку.
- Для входа из номера телефона создаётся технический email `obed.<номер>@gmail.com`. Письма не отправляются.
  Если Supabase отклоняет такой адрес, поменяйте `EMAIL_DOMAIN` в `config.js`.
- Бонусы считаются на сервере: 5% с оплаченных заказов от суммы деньгами, списание проверяется базой.
- Цены и время приёма заказов проверяются на сервере, пользователь не может поставить себе «Оплачен».
